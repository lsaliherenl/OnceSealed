# OnceSealed web app

Next.js 16 (App Router, Cache Components) · Tailwind CSS 4 · viem. The visual design started from a Claude Design
export; all data is real repository data.

| Route | Screen | Data |
| --- | --- | --- |
| `/` | Overview | `src/data/site.json` |
| `/projects`, `/projects/[id]` | 11 published quality reports, ICVCM methodology status, quotes with pages | `site.json` (prerendered); the report hash is compared with `latestReport` on Sepolia in the browser |
| `/verify` | Look up a retirement or simulated serial, check a receipt | Sepolia, read from the browser (`src/lib/chain.ts`); no OnceSealed server involved |
| `/retire` | Registry operator retires whole lots for a fictional buyer | API via `src/app/api/os/[...path]/route.ts` |
| `/auditor` | Open a sealed vault, review the six checks, attest once | API via the same proxy |

```bash
npm ci
npm run build && npm start      # production; use this for demos
npm run dev                     # development
npx eslint src
```

- `src/data/site.json` is generated by `python scripts/export_web_data.py` (CI fails if it is stale).
- `src/lib/registryAbi.ts` is generated by `python scripts/export_artifact.py`.
- `src/lib/chain.ts` re-implements the commitment and LEI checks of `core/privacy/` with viem; the receipt check mirrors
  `OnceSealed.verify_receipt`.
- RPC: `NEXT_PUBLIC_SEPOLIA_RPC_URL` if set, otherwise public endpoints (no key in the browser).
- The proxy forwards only the routes the two role screens use and adds `OPERATOR_API_TOKEN` / `AUDITOR_API_TOKEN`
  from the environment or the repository's `.env`. API address: `ONCESEALED_API_URL` (default `http://127.0.0.1:8000`).
  Demo only: do not expose a server with the tokens configured.
- Known dev-mode quirk: opening `/verify?q=…` directly under `next dev` can leave the panel unrendered; the production
  build renders it.
