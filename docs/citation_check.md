# Citation check

Generated by `scripts/citation_check_metrics.py` from [`data/eval/citation_check/`](../data/eval/citation_check/).

On 30,000-character excerpts the checklist answered "yes" on questions the gold set marks "no" for the 2,500-character excerpt, each citing a paragraph from the extra text. Each cited paragraph (up to two per question) was judged on its own, mixed with length-matched decoys the model did not cite, without showing which was which.

- Cited paragraphs judged to be evidence: 54/77 (70%, 95% interval 59-79%)
- Decoys judged to be evidence: 2/30 (7%, 95% interval 2-21%)

Caveats: "evidence" means the paragraph contains what the question asks for, not that it is true. Questions still answered "no" on the long excerpt were not re-checked, so recall on the long excerpt is known only for the gold set's positives.
