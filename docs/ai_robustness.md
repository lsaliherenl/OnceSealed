- **Evidence deleted**: an answer that stays "yes" may still be right when another paragraph of the excerpt holds the same kind of evidence.
- **Injections**: the paragraph is placed second in the excerpt; no answer cited it as evidence. The screen removes instruction-like paragraphs before any model sees them; it is a pattern match, so a wording it does not know (the soft variant) reaches the model, which is why the model alone is reported too.
- **Unrelated text**: any "yes" would be an answer with no basis in the text.
